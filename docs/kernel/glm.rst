GLM
===

GLM is the executable format used by IsnaOS golems.

GLM binaries are typically generated by the Shape assembler and loaded through the kernel golem loader.

Executable Layout
-----------------

A GLM image contains:

- header
- code section
- data section
- BSS region

The loader allocates memory for the complete image and maps sections into a single contiguous memory block.

Host API
--------

Golems receive a ``glm_host_api_t`` structure containing kernel helper
functions.

Current host API includes:

- text printing
- yielding
- offset-based string printing
- exit handling
- keyboard input
- integer printing

Execution Flow
--------------

``glm_load_and_run(filename)``

1. Read file from VFS
2. Validate GLM header
3. Allocate executable image
4. Copy code/data sections
5. Zero BSS region
6. Invoke executable entrypoint

Notes
-----

The current loader is primarily intended for Shape-generated programs rather than full compiled C programs.

Future versions may include:

- relocations
- symbol tables
- dynamic linking
- process isolation
